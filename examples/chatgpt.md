# ChatGPT

1. In ChatGPT on the web, open <https://chatgpt.com/plugins>.
2. Choose **+**, then **Add custom MCP server**.
3. Paste `https://daysli.com/mcp` and choose **OAuth**.
4. Accept ChatGPT's warning about custom servers, create it as a plugin and install it.
5. Daysli's sign-in opens: sign in and approve the permissions you want.
6. In a chat, type **@** and pick Daysli.

ChatGPT asks you to confirm each change. Which ChatGPT plans offer custom MCP servers is decided by OpenAI.
Daysli is not listed in ChatGPT's app directory yet.
